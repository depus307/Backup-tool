# BackupTool 2.2 — архив сайтов

Распакуйте ZIP целиком и откройте `BackupTool.exe` из папки поставки. Для переноса на другой компьютер скопируйте всю папку вместе с `_internal`.

Требования — Windows 11 x64 и установленный Google Chrome. Python для запуска EXE не нужен. При первом запуске программа покажет инструкцию. Её можно снова открыть на вкладке «Инструкция» в разделе «О приложении». Наведите указатель на кнопку, чтобы увидеть подсказку.

## Первый архив

1. В поле «Список сайтов» выберите XLSX, CSV, TSV или TXT. Для таблицы достаточно столбца «URL», «Ссылка», «Адрес» или «Сайт». «ИНН» и «Компания» можно добавить для поиска. В TXT можно указать по одному HTTP/HTTPS-адресу на строку. Программа читает все листы XLSX. Файл XLS сначала сохраните как XLSX.
2. Проверьте общую папку в поле «Сохранять в». При первом запуске программа подставляет UNC-путь из настроек поставки. Команда «Действия → Загрузить список» показывает строки в таблице перед запуском.
3. Нажмите «Начать обработку». Прогресс отображается над таблицей. Кнопка «Журнал» показывает события с местным временем, а «Отчёт Excel» открывает последний XLSX выбранного списка.
4. Готовые файлы открываются из карточки выбранной строки. «Открыть архив» открывает папку назначения в Проводнике.

Если при отправке пропала связь или не хватило прав, кнопка «Не отправлено» показывает файлы, их папки назначения и ошибки. Когда доступ восстановится, нажмите «Повторить отправку» в этом окне. Программа использует сохранённые файлы даже после перезапуска. Изменение поля «Сохранять в» применяется к следующим бэкапам. Уже ожидающие файлы сохраняют выбранные для них папки.

«Остановить» сохраняет уже готовые файлы. «Продолжить» пропускает их и обрабатывает оставшиеся строки. В меню «Действия» есть команда «Обновить готовые» для повторного сохранения всех сайтов. Щадящий режим в поле «Нагрузка» уменьшает число одновременно открытых страниц. Если загружено несколько списков, переключатель появляется над таблицей.

Таблица показывает по 500 строк. Поиск работает по ИНН, компании и адресу. В списке фильтров можно выбрать конкретный статус или «Нужны действия». Ctrl+A выбирает весь текущий фильтр, Ctrl+C копирует выбранные строки. Правый клик и меню «Копировать» дают команды для отдельных полей. Карточка выбранной строки находится справа, а при узком окне переходит под таблицу. В карточке можно открыть историю сохранения сайта.

## Где лежат файлы

- В папке назначения лежат готовые снимки и скачанные оригиналы. Имена новых снимков имеют вид `ИНН_Название-компании_2026-11-27.pdf`. Если ИНН отсутствует, имя начинается с названия компании или домена сайта. Дата берётся из того же времени, что и подпись на PDF. При совпадении имён после даты добавляется `_1`, `_2` и далее. Для скачанного PDF создаётся полная копия с подписью и сохраняется оригинал. Оба файла доступны из истории попыток.
- Рабочий архив находится в `%LOCALAPPDATA%\BackupTool\archive`. При обновлении с предыдущей версии программа продолжает использовать найденный локальный архив.
- `captures` в рабочем архиве содержит локальные копии. Они используются для повторной отправки, локальной проверки целостности и открытия файлов при недоступности сети.
- `exports` — отчёты XLSX и CSV с результатом, временем обработки, HTTP-статусом и датой снимка. В XLSX есть листы «Все результаты», «Нужны действия» и «Снимки с предупреждениями». Отчёт появляется после прогона. Команда «Действия → Выгрузить XLSX + CSV» создаёт его по запросу.
- `archive.sqlite3` — скрытая база со списками, результатами и путями к файлам. При переносе архива копируйте всю папку после закрытия программы.
- `.writer.lock` — скрытая блокировка, которая разрешает запись в архив одному процессу.
- `.work` — скрытая временная папка. Нужна, пока программа проверяет и переносит снимок в `captures`, а также для восстановления при прерывании. Пустые временные папки удаляются.

## Снимок состояния сайта на дату проверки

Программа сохраняет страницу как она отображается в браузере: в том числе заглушку неоплаченной подписки, страницу ошибки HTTP 402/403/404/500, требование входа или проверку доступа. Проверки доступа автоматически не проходятся. Сохранённый PDF фиксирует увиденную страницу, а не подтверждает доступность основного содержимого сайта.

Страница с ошибкой получает жёлтую отметку «Сохранено как ошибка» с HTTP-кодом, если он известен. Зелёным отмечаются успешные сохранения. Капча Google и пустая страница дают результат «Ошибка» в фильтре «Нужны действия» без нового PDF. Чтобы повторно проверить и уже сохранённые снимки, используйте «Действия → Обновить готовые». Предыдущие файлы остаются в истории.

При ошибке DNS, соединения, TLS или таймауте PDF включает фактический экран ошибки браузера, когда он доступен. При отсутствии экрана PDF содержит адрес и диагностику соединения. Если загрузка прервалась после получения страницы, её содержимое сохраняется с отметкой о неполной загрузке.

Если ссылка на PDF или другой документ возвращает HTML-заглушку, она сохраняется как страница PDF с датой и HTTP-статусом. Настоящие документы скачиваются без изменения содержимого. Для прикреплённого вручную PDF дата проверки сайта и HTTP-статус не придумываются.

При первом обращении рабочего процесса к старому архиву добавляются поля метаданных. Старые снимки сохраняются, их дата и HTTP-статус задним числом не заполняются. Часы и часовой пояс берутся с компьютера, выполняющего сохранение.

Полный список изменений приведён в `CHANGELOG.md` и в окне «О приложении → Changelog».

## Если нужно открыть основное содержимое вместо заглушки

1. Выберите фильтр «Нужны действия», затем строку и кнопку «Помочь открыть сайт».
2. В отдельном окне Chrome пройдите проверку или войдите. Это окно использует отдельный сеанс браузера.
3. Вернитесь в BackupTool, выберите нужную вкладку в карточке и нажмите «Сохранить PDF вкладки». Программа печатает содержимое этой вкладки без перезагрузки сайта.
4. Если у вас уже есть PDF, выберите «Прикрепить PDF…». Программа проверит структуру файла, скопирует его в архив и свяжет с выбранной строкой.

Команда «Действия → Проверить файлы списка» сверяет хеши и проверяет структуру PDF. Если файл пропал или изменился, повторите обработку.

## Разработка

Публичная сборка поставляется с пустым путём назначения. Чтобы подставлять один UNC-путь на всех рабочих местах при первом запуске, скопируйте `_internal/delivery.json` рядом с `BackupTool.exe` под именем `delivery.local.json`. Задайте в нём `default_destination`, указав сервер и общую папку с двойными обратными косыми чертами по правилам JSON. При запуске из исходников `delivery.local.json` размещается рядом с `launcher.py`.

Команды выполняются из корня исходников с Python 3.12.14 x64. Зависимости закреплены в `requirements.lock`.

```powershell
& .venv/Scripts/python.exe launcher.py
& .venv/Scripts/python.exe -m unittest discover -s tests
& .venv/Scripts/python.exe -m tools.check_manual_delivery
& .venv/Scripts/python.exe -m tools.check_snapshot_delivery --manual
& .venv/Scripts/python.exe -m PyInstaller --noconfirm --workpath .build/application --distpath .build/delivery BackupToolNext.spec
& .venv/Scripts/python.exe -m tools.check_frozen_delivery
& .venv/Scripts/python.exe -m tools.check_snapshot_delivery --exe dist/BackupToolNext/BackupTool.exe
```

PyInstaller помещает сборку в `.build/delivery`. Папка сборки отделена от рабочего архива. Проверки используют локальный HTTP-стенд, а проверка ручного сохранения открывает окно Chrome.
